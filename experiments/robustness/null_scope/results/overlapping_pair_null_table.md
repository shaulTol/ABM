Observations on this finite grid (NOT proven bounds, and not extrapolable beyond the configurations listed): (i) with overlap (P > 1) the overlapping-pair null maximum was never below the independent-pair null maximum at matched M; (ii) with overlap, the median and q95 of the overlapping-pair `lambda_max` stayed below the practical reference edge at `gamma_traj` (max q95/ref = 0.995; the largest single replicate reached 1.006); (iii) for P = 1 the two aspect ratios coincide, so the usual finite-sample fluctuation above the edge is visible there (q95/ref up to 1.017). Theorem 2 applies at `gamma_pair`; the `gamma_traj` edge is only an operational reference.
