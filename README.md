# ABM — Autocorrelation-Based Multimodality

Code and results for the paper *"Measuring and Decomposing Multimodality via Canonical Diffusions"*. The ABM framework provides two tools: **SSA** (Sum of Squared Autocorrelations), a scalar multimodality measure, and **DA** (Dominant Autocorrelation) directions, a directional decomposition ordered by metastability.


## Setup

```bash
# Create conda environment
conda create -n abm python=3.12
conda activate abm

# Install dependencies
pip install -r requirements.txt
```

For SDXL experiments, additionally install:
```bash
pip install latent_clip open_clip_torch==3.3.0
pip install diffusers==0.30.0  # reinstall after latent_clip pins 0.28.0
```

```
experiments/

  da_directions/   DA vs TICA comparison (Section 4.3, 4.5)
  mnist/           DDPM-based MNIST SSA + DA (Section 4.4)
  sdxl/            SDXL latent-space SSA (in progress)
```

## Reproducing Experiments

### GMM Sweeps (Section 4.1-4.2)
```bash
cd experiments/gmm_sweep
python run_all.py           # Run all 13 sweep configs
python run_random_sweep.py  # Run random parameter sweep
python plot_paper_figures.py
```

### DA Directions (Section 4.3, 4.5)
```bash
cd experiments/da_directions
python parallel_ellipses.py         # 2D toy example
python compute_da_comparison.py     # Alanine + chignolin (requires MDShare data)
python make_paper_figures.py
```

### MNIST (Section 4.4)
```bash
cd experiments/mnist
python scripts/train_mnist_ddpm.py configs/mnist.yaml   # Train DDPM (~1.5h on GPU)
python scripts/compute_mnist_ssa.py                      # SSA for all 10 digits
python scripts/compute_mnist_da.py                       # DA directions
python scripts/visualize_results.py
```

## Regenerating Figures

All 15 paper figures have pre-generated PNGs in `figures/`. To regenerate:
```bash
cd figures
python make_fig_gmm_sweeps_split.py            # fig_gmm_sweeps_{curves,snapshots}.png
python make_fig_dispersion_vs_fragmentation.py  # fig_dispersion_vs_fragmentation.png
python make_fig_da_parallel_ellipses.py         # fig_da_parallel_ellipses_2panel.png
python make_fig_da_parallel_ellipses_convergence.py
python make_fig_mnist_ssa_entropy_bars.py       # fig_mnist_ssa_entropy_bars.png
python make_fig_mnist_clusters_compact.py       # fig_mnist_clusters_compact.png
```

Remaining figures (alanine, chignolin, 10D sweeps, MNIST DA) are generated by experiment-specific scripts.
