# ABM — Autocorrelation-Based Multimodality

Code and results for the paper *"Measuring and Decomposing Multimodality via Canonical Diffusions"*. The ABM framework provides two tools: **SSA** (Sum of Squared Autocorrelations), a scalar multimodality measure, and **DA** (Dominant Autocorrelation) directions, a directional decomposition ordered by metastability.


## Setup

```bash
# Create conda environment
conda create -n abm python=3.12
conda activate abm

# Install dependencies
pip install -r requirements.txt
```

## How SSA and DA Are Computed

The framework has four stages: **Langevin simulation** → (optional embedding) → **autocorrelation** → **SSA score + DA directions**.

### 1. Langevin Simulation

We run overdamped Langevin dynamics (Euler-Maruyama) starting from samples of the target distribution f:

```
X_{t+dt} = X_t + (σ_f²/2) · ∇log f(X_t) · dt + σ_f · √dt · Z
```

where `σ_f² = tr(Cov_f)/d` is a scalar diffusion coefficient (average per-dimension variance), making the process scale- and rotation-invariant. Snapshots of the trajectory are saved at ~20 linearly-spaced lags.

**Key files:**
- `src/simulation/langevin.py` — `LangevinSimulatorD` for GMMs (analytical score via responsibility-weighted precision)
- `src/simulation/generic_langevin.py` — `GenericLangevinSimulator` for arbitrary score functions
- `experiments/sdxl/scripts/compute_sdxl_ssa_v2.py` — SDXL score via Tweedie formula (`SDXLScore`), always at `t=1`

### 2. Autocorrelation

At each snapshot lag τ, we compute the trace-normalized autocorrelation:

```
ρ(τ) = tr(C(τ)) / tr(C(0))
```

where `C(τ) = (1/N) Σ_n (z_τ^(n) − μ)(z_0^(n) − μ)^T` is the lag-τ autocovariance matrix.

**Key files:**
- `src/metrics/autocorrelation.py` — `compute_autocorrelation` (1D, line 52), `compute_vector_autocorrelation` (multidimensional, line 113)
- `experiments/sdxl/scripts/sdxl_components.py` — `compute_ssa_da()` (CLIP-space version, line 146)

### 3. SSA (Sum of Squared Autocorrelations)

```
SSA = (1/L) Σ_{τ=1}^{L} ρ(τ)²
```

The mean of squared autocorrelations over lags. A unimodal distribution mixes fast (ρ decays quickly → SSA ≈ 0), while a bimodal distribution has slow mixing (ρ stays elevated → SSA ≈ 1).

**Key function:** `compute_ssa_score` in `src/metrics/autocorrelation.py` (line 291)

### 4. DA Directions (Dominant Autocorrelation)

At each lag τ, we symmetrize and eigendecompose the autocovariance matrix:

```
C_sym(τ) = ½(C(τ) + C(τ)^T)
eigenvalues, eigenvectors = eigh(C_sym)
```

The **optimal lag** τ\* is chosen where the eigenvalue gap |λ₁|/|λ₂| is maximized. The leading eigenvector DA1 at τ\* points along the slowest-mixing direction — the one separating the modes. At τ=0 these reduce to PCA directions; as τ grows, fast intra-mode relaxations decay and inter-mode transitions dominate.

**Key functions:**
- `extract_da_directions` in `src/metrics/da_directions.py`
- `da_convergence_profile` (same file, line 136) — tracks eigenvalue gap over lags

### SDXL-Specific Pipeline

For SDXL experiments, after Langevin simulation in 16384D latent space, snapshots are projected into CLIP embedding space before computing SSA/DA:
- **LatentCLIPEmbedder** — maps VAE latents directly to 512D (fast)
- **RealCLIPEmbedder** — VAE decode → CLIP ViT-L/14 → 768D (semantically richer)

After DA1 is found, `TextProbeAnalyzer` computes cosine similarity with text-derived directions (e.g. gender, age) to interpret what the DA direction captures.

### Key Parameters

| Parameter | Typical Value | Effect |
|-----------|--------------|--------|
| `dt` | 0.0001 | Step size; larger values jump over barriers → wrong SSA |
| `T` | 500 | Total Langevin steps; must allow inter-mode transitions |
| `t` (score) | 1 | DDPM noise level; always 1 (min noise). Higher t smooths away metastability |
| `ssa_min_lag` | 0 or 100 | Filter early lags from SSA (removes fast intra-mode relaxation) |
